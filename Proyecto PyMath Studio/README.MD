# PyMath Studio

Sistema matematico desarrollado en Python con Tkinter para practicar calculo y operaciones basicas.

## Funcionalidades

- Menu principal sin inicio de sesion.
- Analisis de continuidad con limites laterales, valor de la funcion y redefinicion cuando corresponde.
- Operaciones matematicas: suma, resta, multiplicacion, division, potencia y raiz cuadrada.
- Graficador de funciones con intervalo configurable.
- Historial de ejercicios en MongoDB o en archivo local si MongoDB no esta disponible.
- Exportacion de resultados a TXT y guardado en el archivo "resultado_continuidad.txt".

## Tecnologias

- Python
- Tkinter --interfaces de usuario
- SymPy --simbologia y uso de operadores para realizar procesos
- Matplotlib --creacion de graficas
- NumPy -- operaciones basicas matematicas
- MongoDB
- PyMongo --libreria para usar base de datos
