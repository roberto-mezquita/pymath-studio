# PyMath Studio

Aplicación desarrollada en Python para el análisis y resolución de funciones matemáticas mediante una interfaz gráfica intuitiva.

## Descripción

PyMath Studio es una herramienta educativa diseñada para apoyar el aprendizaje de conceptos matemáticos relacionados con funciones, continuidad y discontinuidad. El sistema permite realizar análisis matemáticos, mostrar procedimientos lógicos y generar representaciones gráficas para facilitar la comprensión de los resultados.

## Funcionalidades

* Resolución de funciones matemáticas
* Análisis de continuidad y discontinuidad
* Generación de gráficas
* Interfaz gráfica amigable
* Presentación paso a paso de procedimientos matemáticos

## Tecnologías utilizadas

* Python
* Tkinter
* Bibliotecas matemáticas y de visualización
* Programación Orientada a Objetos (POO)
